# MediCore HIMS

**MediCore Hospital Information Management System**

MediCore HIMS is a Java Swing desktop application with a REST API backend, designed to help manage hospital workflows.

## Download

Download the Windows installer from the [latest release](https://github.com/mironvincent/medicore-hims-downloads/releases/latest).

## Installation

1. Download the Windows installer (`.exe`) from the Releases page.
2. Run the installer.
3. Follow the installation instructions.
4. Launch MediCore HIMS.

## Version

Current release: v1.0.0

## Project

MediCore HIMS is a student software project. Please verify the application's requirements and configuration before use.
